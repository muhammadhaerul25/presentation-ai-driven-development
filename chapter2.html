📄 Requirements 🎨 UI/UX Design 💻 Codebase 🐛 Error Logs

The process of providing structured, relevant, and sufficient information to AI systems.

Technique 01 — Persona & System
01 Persona & System

Set the Role & Tone

Set the role, expertise, behaviour, constraint, and tone for the AI before the task begins — for the entire conversation.

Structure
[Role]You are a [specific role]
[Expertise]Working in [domain/environment]
[Behavior]You should [how to respond]
[Constraint]You must not [what to avoid]
[Tone]Always respond in [format/style]
Role-play prompting surpasses zero-shot across benchmarks. AQuA accuracy: 53.5% → 63.8% (+10.3%)

Technique 02 — Few Shot
02 Few Shot

Guide with Examples

Provide the AI with context and examples to control the structure and style of the expected output.

Structure
[Context]Background of the situation
[Objective]The specific task you want done
[Rules]Constraints, tech stack, requirements
[Examples]Example the AI should follow
Few-shot examples pushed GPT-4o pass@1: 47.1% → 57.5% on CodePromptEval
Bad Prompt Good Prompt
User
"Create a login page for this web application"

Exact stack, matches example pattern
Technique 03 — Chain of Thought
03 Chain of Thought

Reason Step by Step

Guide the AI to solve a problem step by step — showing its reasoning process before giving the final answer.

Structure
[Problem]The task or question
[Trigger]"Think step by step" / "Let's reason through this"
[Steps]Step 1: ... → Step 2: ... → Step N: ...
CoT prompting shows accuracy improvements of up to +18% on arithmetic tasks (Wei et al., 2022)
Bad Prompt Good Prompt
User
"Why is the RAG Chatbot response inaccurate?"
AI Response
Single guess, no reasoning
"Why is the RAG Chatbot inaccurate?
Think step by step:
Step 1: Check retrieval — right doc?
Step 2: Check chunking — too large/small?
Step 3: Check embedding model
Step 4: Check model capability
Step 5: Root cause & concrete fix."
AI Response
Systematic diagnosis + root fix
Technique 04 — Tree of Thought
04 Tree of Thought

Explore Multiple Paths

Guide AI to explore multiple reasoning paths simultaneously, evaluate each one, and select the best solution.

Structure
[Problem]The task or question
[Explore]Generate N different approaches (A, B, C…)
[Evaluate]Evaluate each based on criteria
[Select]Select the best approach
[Conclude]Final answer based on the best path
ToT achieves 74% accuracy vs GPT-4 default 7.3% on multi-step tasks (Yao et al., 2023)
Bad Prompt Good Prompt

Technique 05 — Multi Stages
05 Multi Stages

Break It Into Stages

Break a complex task into a sequence of smaller, focused prompts — where the output of one stage becomes the input of the next.

Structure
1Define the goal and requirements
↓
2Plan the approach
↓
3Execute the task
↓
NRefine and finalize
Multi-stage approach vs direct: success rate 29.2% → 78.5% (+49.3pp) — Prompt2DAG, 2025
Bad Prompt Good Prompt
User
"Build a complete AI Price Comparison Agent"
AI Response
Incomplete, missing edge cases

↓
Stage 2 Design

↓

Generate code → review → fix → add tests
