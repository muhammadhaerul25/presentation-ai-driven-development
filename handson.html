main.py — skeleton 
from fastapi import FastAPI, UploadFile, File
from fastapi.middleware.cors import CORSMiddleware
from PIL import Image
import io, json, re

app = FastAPI()
app.add_middleware(CORSMiddleware,
  allow_origins=["*"])

def clean_json(text: str) -> str:
    # Strip ```json...``` fences from Gemini
    text = re.sub(r'```json\s*', '', text)
    text = re.sub(r'```\s*', '', text)
    return text.strip()

def gemini_crop(image, bbox, label):
    # Normalize or pixel coords → crop + pad
    if bbox is None: return image
    x1,y1,x2,y2 = bbox
    if max(bbox) <= 1.0:  # normalized
        w,h = image.size
        x1,x2 = x1*w, x2*w
        y1,y2 = y1*h, y2*h
    return image.crop((x1-10,y1-10,x2+10,y2+10))

@app.post("/detect")
async def detect(image: UploadFile = File(...)):
    data = await image.read()
    img = Image.open(io.BytesIO(data))

main.py — Gemini pipeline (Step 3 of 3) 
# Step 1 — Vehicle Detection
try:
    r1 = model.generate_content([img, """
Detect the main vehicle in this image.
Return ONLY valid JSON, no explanation:
{'vehicle_bbox': [x1,y1,x2,y2]}
If no vehicle: {'vehicle_bbox': null}"""])
    d1 = json.loads(clean_json(r1.text))
    v_crop = gemini_crop(img, d1['vehicle_bbox'], 'vehicle')
except: v_crop = img  # fallback: use original

# Step 2 — Plate Detection
try:
    r2 = model.generate_content([v_crop, """
Detect the license plate in this vehicle image.
Return ONLY valid JSON, no explanation:
{'plate_bbox': [x1,y1,x2,y2]}
If no plate: {'plate_bbox': null}"""])
    d2 = json.loads(clean_json(r2.text))
    p_crop = gemini_crop(v_crop, d2['plate_bbox'], 'plate')
except: p_crop = v_crop  # fallback: vehicle crop

# Step 3 — OCR
r3 = model.generate_content([p_crop, PROMPT_OCR_PLATE])
result = json.loads(clean_json(r3.text))
if isinstance(result, list): result = result[0]
return result

Common Fixes
Fix 1 Gemini returns JSON in markdown fences

Gemini wraps output in ```json ... ```. Fix clean_json() to strip all fence formats including those without a language tag.

Fix 2 Bounding box crops wrong region

Gemini may return normalized coords (0.0–1.0) instead of pixels. Detect and multiply by image dimensions. Add 10px padding and clamp to image bounds.

Fix 3 OCR response parsing crashes

Step 3 sometimes returns an array, sometimes an object. Handle both: if list → return result[0]; if dict → return directly; if empty → raise 500.

Key Takeaways
01

Pipeline Thinking

Complex AI tasks are just simple steps chained together. Vehicle detect → plate detect → OCR. Break every problem into the smallest possible steps.

02

Context Is Everything

Gemini reads a plate more accurately when it sees just the plate — not the full original image. Cropping is context engineering, not just image processing.

03

The Prompt Is the Product

A precise, well-structured prompt is the core intellectual property of an AI application. The prompt is more valuable than the code around it.
